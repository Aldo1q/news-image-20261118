# Sum up 18 November's world news in one image

Entry for the make.fun bounty `news-image-20261118`.

`main.py` writes the image to `/output/entry.png`. The program is
deterministic: it copies `entry.png`, the front page summarising the
world news of Wednesday 18 November 2026, into `/output`. No network.

The image is a 1024x1024 PNG (under 1 MiB): a front page with the day's
top stories — Trump in Manila for Quad talks ahead of APEC, Ukraine's
Crimean bridge strikes, Iran drones hitting a US radar in Bahrain, the
Dow's 1,000-point plunge, Nvidia's record quarter, and Canada–China
trade deals — plus a ticker of further headlines.
